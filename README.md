# 🧮 Classic Calculator (Premium Edition)

A high-performance, feature-rich web calculator with a stunning UI and modular theme system. Designed for both simplicity and advanced scientific computations.

## ✨ Features

- **Dual Modes**: Smoothly toggle between **Standard** and **Scientific** calculators.
- **Theme Engine**: Includes 7+ curated presets (Neon, Cyberpunk, Forest, etc.) and a **Live Custom Theme Editor**.
- **Calculation History**: Persistent history panel to track and reuse your previous results.
- **Full Keyboard Support**: Type naturally with real-time visual feedback for every keypress.
- **Premium Aesthetics**:
  - **JetBrains Mono** typography for maximum readability.
  - Smooth 60fps animations and transitions.
  - Floating Action Button (FAB) menu for a clean, clutter-free workspace.
- **Persistence**: Automatically saves your theme, custom colors, and history to LocalStorage.

## 🛠️ Technology

- **HTML5**: Structured for accessibility and semantic clarity.
- **CSS3**: Advanced CSS Variables, Flexbox/Grid layouts, and hardware-accelerated animations.
- **JavaScript (Vanilla)**: Efficient event delegation, state management, and custom theme logic.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser.

```bash
# Clone the repository
git clone https://github.com/yourusername/classic-calculator.git

# Navigate and Open
cd calculator
open index.html
```

## ⌨️ Shortcuts

- `0-9`, `.`, `+`, `-`, `*`, `/`: Standard input.
- `Enter` or `=`: Calculate.
- `Backspace`: Delete last character.
- `Escape` or `C`: Clear display.
- `M`: Toggle main menu.
- `^`: Power function (Scientific mode).
